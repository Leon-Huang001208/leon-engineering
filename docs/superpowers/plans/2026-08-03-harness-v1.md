# Harness v1 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` or an equivalent inline TDD loop. Steps use checkbox syntax for tracking.

**Goal:** 为用户明确选择的项目提供跨 Codex/Claude 可发现的本地 Agent Map、任务交接账本和交付指标，并保持默认只读与显式写入边界。

**Architecture:** 新建独立的 `harness-project.mjs`，复用 `profile-project.mjs` 的受限项目解析，不读取环境变量、不执行项目命令。普通模式只输出待写入的 Harness 结构；`--write-harness` 才创建 `.ai/harness/`。结果记录必须由单独的 `--record-outcome` 显式写入，禁止把未运行验证当成结果。

**Tech Stack:** Node.js ESM、Node 内置 `node:test`、JSON/Markdown、既有 Codex/Claude 适配器。
