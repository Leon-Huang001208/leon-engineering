# 高吞吐交付试点

本试点只在合成 Git 仓库中运行，用可复现的读取、修改、差异和测试记录验证交付路径；不使用生产凭据或真实全局配置。

## 快路径

在合成 Git 仓库中修改一个已点名函数，并运行唯一的目标测试。记录读取的文件、修改的文件和实际测试命令；不创建计划、代理或 worktree。

## 只读调研

让 `repo-explorer` 只读取三份已点名文件。记录其返回的证据，并运行 `git diff --exit-code` 证明没有改动；非零退出必须作为失败证据记录。

## 隔离实现

在合成仓库创建子 worktree，由 `implementer` 仅修改两份已点名文件及目标测试，并运行该目标测试；随后验证父检出仍干净。

任何未返回的非交互 CLI 调用都是限制而非成功，不以耗时宣称代替实际证据。
