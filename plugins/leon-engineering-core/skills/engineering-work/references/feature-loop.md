# Feature Loop

Derive outcome, acceptance criteria and affected contracts from the task and code. Existing authorization persists; ask only for a concrete missing input. Use the risk route from agent-routing; keep the project's required isolation and checks.

Implement the smallest complete slice. Use TDD when useful; otherwise implement, directly check the result and deliver. Run only relevant checks and reuse still-valid results. Do not add speculative protection, approvals, receipts or recovery rehearsals. Necessary CI and branch protection still apply.

Read the relevant section of the [engineering methods reference](engineering-methods.md) for language checks, test design, bounded maintenance or an architecture decision within the accepted scope. Clear tasks do not require another interview.

Hand off changed files, real commands/results, omitted checks, rollout risks and follow-up work. Do not claim unobserved browser, platform or CI success.
