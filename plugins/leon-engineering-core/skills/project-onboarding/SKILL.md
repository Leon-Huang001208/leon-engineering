# Project Onboarding

### Inspect by default

Read project instructions first. Use [project profiling](references/project-adapter.md) to identify candidate tools, checks and constraints. A candidate is not evidence that a command passed.

### Propose or apply project setup

Use [project bootstrap](references/project-bootstrap.md) to propose the smallest useful rule and validation changes. Write project configuration only after explicit authorization for that project.
