# Dual-layer Explanation

## Triggers

Use for unfamiliar, abstract, or cross-functional concepts where intuition and precision are both needed.

## Anti-triggers

Do not use for a terse command, a simple fact, or when the user explicitly requests code only.

## Inputs

Audience level, concept, decision context, and required technical depth.

## Procedure

1. Give a compact intuitive model with one concrete example.
2. State where the analogy stops being accurate.
3. Provide the exact mechanism, interfaces, and constraints.
4. Reconnect the technical layer to the user’s decision.

## Observable output

Two labeled layers plus an explicit analogy boundary and one decision implication.

## Composition

Combine with `reverse-engineering` or `fact-checking`; use no more than three reasoning skills total.

## Permissions

This skill grants no data, file, network, dependency, delivery, or destructive permission.
