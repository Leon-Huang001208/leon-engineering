# Steelman Comparison

## Triggers

Use for consequential alternatives, contested interpretations, or decisions vulnerable to confirmation bias.

## Anti-triggers

Do not manufacture balance between evidence-rich and baseless claims, or simplify with a straw man.

## Inputs

Alternatives, shared criteria, strongest supporting evidence, constraints, and disconfirming conditions.

## Procedure

1. State the strongest viable form of each option.
2. Apply identical criteria and evidence standards.
3. Name each option’s decisive advantage and strongest objection.
4. Recommend conditionally using decision-changing variables.

## Observable output

A symmetric comparison with strongest cases, objections, deciding variables, and conditional recommendation.

## Composition

Combine with `fact-checking` or `expert-perspectives`; use no more than three reasoning skills total.

## Permissions

This skill grants no data, file, network, dependency, delivery, or destructive permission.
