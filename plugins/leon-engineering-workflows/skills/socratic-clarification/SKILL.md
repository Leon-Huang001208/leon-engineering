# Socratic Clarification

## Triggers

Use for material ambiguity, conflicting goals, undefined terms, or missing acceptance criteria.

## Anti-triggers

Do not use when the request and reversible implementation path are already clear, or merely to delay execution.

## Inputs

The stated goal, known facts, constraints, decisions already made, and the smallest unresolved decision.

## Procedure

1. Restate the intended outcome without adding scope.
2. Separate verified facts, assumptions, and unknowns.
3. Ask only questions whose answers change the implementation or conclusion.
4. When safe, proceed under a clearly stated reversible assumption.

## Observable output

A short decision record listing the clarified goal, constraints, assumptions, and remaining blocking question.

## Composition

Combine with `first-principles` or `minimal-experiment`; use no more than three reasoning skills total.

## Permissions

This skill grants no data, file, network, dependency, delivery, or destructive permission.
