本受管区块优先于旧目录或旧代理目录中“默认先规划、先委派或全量验证”的建议；项目规则和明确风险升级要求仍优先。

在选择执行路径前，优先检查已安装的 skill、agent 和工具是否直接匹配当前任务；命中则按其触发条件使用，未命中才以通用能力直做。该本地能力检查属于快路径，不创建计划、子代理或 worktree；不能把未检查可用能力合理化为直接执行。

范围明确、可逆且能在本地完成的任务，默认走快路径：先只读与当前任务直接相关的文件，再直接实施，并只运行能够证明本次改动的最小相关验证。

快路径中不得为了流程创建计划、子代理或 worktree，不运行无关检查，也不得进行流程性提问。主代理负责汇总变更、验证证据和未验证项。

范围不明、调研受阻、并行工作有明确速度收益，或需要因风险、耦合而隔离时，才升级处理方式。涉及秘密、依赖、远程变更、发布、部署、迁移、CI/CD、系统配置、破坏性操作或外部协调时，必须先询问并获得明确授权。

在执行中主动提炼跨项目可复用的错误和经验；不得等待用户再次指出。对有实际证据且不改变权限、秘密、依赖、远程、发布、迁移、CI/CD、系统配置或破坏性边界的低风险修正，自动更新受管源、测试和安装副本，并记录验证证据。上述高风险类别或影响面不明的修正必须先取得明确确认；项目特定事实不提升为全局规则。

跨宿主可用能力以 `docs/shared-capability-catalog.md` 为共享能力目录；只路由其中明确标记为共享的 skill 和职责代理。不在共享目录的 Claude 专用 skill、agent 或规则只能作为候选证据，不得隐式复制、安装或当成 Codex 默认能力。

修改任何共享 skill 时必须同步更新其文档；添加或更新任何依赖（包括 Python 依赖）前，必须说明用途、影响和目标文件并取得用户明确同意。

对已初始化 Harness 的多任务依赖、显式重试或中断恢复，先用 P2 控制平面预览任务 DAG。它只保存项目内任务状态和已存在 worktree 的定位信息；不得自动创建、切换或删除 worktree，不得自动重试，也不得运行 Git、测试、构建或任务命令。
