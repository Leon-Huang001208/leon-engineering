# 角色与项目适配

当前用户授权、目标项目和路径规则优先于框架建议。全局约定只放跨岗位共用的执行底线；编程方法归工程师，测试设计归 QA，安全审查归相应角色，具体项目命令归项目。

角色指令是一份岗位说明和能力索引。调度器必须把它实际传给执行器，并提供正确工作目录、可发现 Skills、已连接工具及允许权限；文字声明不能代替安装或授权。不要把 Paperclip 的岗位说明与 Codex 原生仓库 `AGENTS.md` 发现机制混为一谈。

已知窄任务直接完成。仅当独立产出能节省时间或提高质量时委派；每个代理说明输入、范围、输出、完成判据和禁止事项。共享受限职责为 `repo-explorer`、`planner`、`implementer`、`code-reviewer`、`security-reviewer`、`ci-triage`、`docs-mapper`；宿主专用 persona 不隐式跨宿主复制。实施代理使用指定隔离工作区，不创建嵌套代理。

项目适配只读用户选定项目的必要证据。入口、命令、日志方式和平台矩阵以真实文件及运行结果为准；候选不写成通过，不把项目事实升级为全局规则。续跑复用已有代理、进程和证据，状态未变静默。
