# 全局工程工作流：快速开始

这套工作流适用于每一个由 Codex 处理的项目类型，包括前端、后端、桌面端、数据工程和文档；它不是某一个仓库的模板。

每次任务按以下顺序工作：

1. 识别用户目标、目标项目和相关项目规则；不把“所有项目”理解成可以批量改写本机仓库。
2. 若任务符合快路径（已知文件、窄范围改动或明确命令），由主会话直接完成。
3. 只有项目陌生且确实需要证据时，才使用 `project-adapter` 生成只读档案；它列出证据与候选命令，但不运行命令，也不代表验证通过。
4. 按任务风险选择最小验证和最少的代理；只在探索、并行或隔离有明确收益时使用 `agent-routing`。
5. 必要时用 `project-bootstrap` 只记录已验证的项目事实；仅在用户明确授权时写入项目档案。
6. 用对应的实现、修复、可观测性和交付工作流完成改动，并报告实际验证结果与剩余风险。

只有用户明确授权时，才通过 `project-adapter --write-profile` 把 `.ai/project-profile.json` 持久化写入某个项目；默认只读且拒绝覆盖。项目特定细节不应被写进全局策略。
