# 工程工作流快速开始

全局入口只保留通用边界。项目规则负责项目命令和验收；Paperclip 等调度器的角色说明负责岗位职责；Skill 提供按需操作方法。普通聊天和已知单条只读请求不启动完整工程流程。

1. 确认目标、当前授权、目标项目及其规则。
2. 对实质工程任务按 `agent-routing` 选择一条功能、修复或评审分支；已安装能力匹配时复用。
3. 局部、可逆且无冲突的小改就地完成；风险或并发需要时隔离实现。风险升级不扩大授权。
4. 运行项目要求和本次风险需要的检查，报告实际结果与未验证项。已通过检查无新理由不重复运行。

`project-adapter` 的候选命令不是验证证据，项目档案只在获准时写入。Harness 和受管交付控制器仅供显式选择它们的项目或任务使用；没有默认账本和自动 Hook。

参见[技能分工](SKILLS_GUIDE.md)、[命令](COMMANDS_GUIDE.md)、[设置边界](SETTINGS_GUIDE.md)。
