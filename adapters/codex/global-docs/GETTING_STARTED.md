# 全局工程工作流：快速开始

这套工作流适用于每一个由 Codex 处理的项目类型，包括前端、后端、桌面端、数据工程和文档；它不是某一个仓库的模板。

每次任务按以下顺序工作：

1. 确认用户目标和目标项目；不把“所有项目”理解成可以批量改写本机仓库。
2. 读取仓库的 `AGENTS.md`、路径级规则、架构/开发文档和现有工具配置；项目规则优先于本全局默认。
3. 对陌生项目先用 `project-adapter` 生成只读档案；它列出证据与候选命令，但不运行命令，也不代表验证通过。
4. 用 `project-bootstrap` 只记录已验证的项目事实，并选择最小的安全验证命令。
5. 用 `agent-routing` 按风险决定直接执行、只读调研、隔离 worktree 或经用户同意的团队。
6. 用对应的实现、修复、可观测性和交付工作流完成改动，并报告实际验证结果与剩余风险。

只有用户明确授权时，才通过 `project-adapter --write-profile` 把 `.ai/project-profile.json` 持久化写入某个项目；默认只读且拒绝覆盖。项目特定细节不应被写进全局策略。
