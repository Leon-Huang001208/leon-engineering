# 全局工程工作流：快速开始

默认仅提供按需 Skill 与短规则，不注册 Hook、不自动建立 Harness，也不默认安装运行时。

1. 先理解用户要解决什么，读取项目规则和必要材料；不跨项目批量扫描。
2. 检查已安装能力，按目标匹配。需求明确就执行；只有答案会改变范围、方案或验收时，问一个关键问题并说明推荐取舍。
3. `agent-routing` 区分只读、本地小改、隔离实现和完整交付；风险升级不授予发布权限。
4. 功能或修复按需进入 `engineering-work`，评审或明确授权的交付进入 `engineering-delivery`；陌生项目使用 `project-onboarding`。
5. 按项目要求验证并报告真实结果。只有项目或任务显式选择 Harness/控制器时，才安装和调用对应运行时。

已知单条只读请求不启动完整工程流程，普通聊天同样不增加流程。新能力安装、全局配置和外部操作遵循当前授权，已有授权持续有效。
