# 工程规则的目录与职责

| 层 | 位置与用途 |
| --- | --- |
| 全局约定 | Codex `AGENTS.md`：语言、授权、证据与按需入口。受管块外的用户规则保持原样。 |
| 项目规则 | 目标仓库的 `AGENTS.md`、文档和配置：架构、测试命令、平台与交付要求。 |
| 岗位说明 | 调度器选定角色的指令文件：工程师、测试、安全、产品等各自的职责和能力索引。 |
| Skills | 规范插件的 `plugins/*/skills/*/SKILL.md`：按任务读取的一份方法真源。 |
| 可选运行时 | 显式安装的 `~/.agents/leon-engineering/runtime/`：手动验证、账本、交付与治理 CLI。 |

`--install-global` 只维护短策略、六份指南和其 manifest，不安装 Hook 或运行时。Skill 插件安装与全局文档安装独立。

调用角色指令必须由执行链实际传入；在角色文件中列出工具名不会安装工具、连接 MCP 或授予权限。手动使用 Codex 时，仍可从项目规则和匹配 Skill 进入工程流程。
