# 全局工程工作流：目录与职责

`~/.codex` 中与本框架相关的内容分为三层：

| 层 | 位置 | 所有者与作用 |
|---|---|---|
| 全局策略 | `AGENTS.md` 中的 `leon-engineering` 标记区块 | 仅提供跨项目默认边界；保留区块外的用户规则。 |
| 全局文档 | `docs/` | 描述可复用的工程流程、技能和安全设置边界。 |
| 工作流技能 | `skills/` | 在任务触发时提供项目引导、实现、修复、交付闭环、审查、日志、路由和技能治理能力。 |

实现性 Git 任务的交付状态不写入聊天记忆，而是由共享运行时保存在 Git common dir 的 `.git/leon-engineering/deliveries/` 与 `.git/leon-engineering/logs/`。仓库工作树不会因此新增受跟踪文件。

框架源文件位于 `leon-engineering` 源仓库，安装器在显式执行时把其副本安装到 Codex home。技能清单与全局文档清单是分离的：更新文档不会获得第三方技能的所有权，更新技能也不会覆盖用户的全局规则。

项目层位于目标仓库。项目的 `AGENTS.md`、模块文档、包管理器、CI、测试与平台支持矩阵始终覆盖全局默认。详见 [代理与规则](AGENTS_GUIDE.md)。
